\section{Method}
\label{sec:method}
As illustrated in Figure~\ref{fig:method}, the proposed pipeline reads one frozen forward pass per image and builds everything from the patch tokens it returns. A single weight, computed from each image's own token self-similarity, discounts repeated content such as sky or a facade of identical windows, and is used by both stages and by the store (\S\ref{sec:feat}). Stage 1 then represents each image by one global descriptor, obtained by pooling its tokens into their weighted second moment, and scans the whole database with it to return a shortlist (\S\ref{sec:global}). Stage 2 re-ranks that shortlist by explicit patch-to-patch \textsc{MaxSim} matching, with patches that have no counterpart in the other image gated out (\S\ref{sec:core}).


\subsection{Preliminaries}
\label{sec:prelim}
A query image $I_q$ is matched against a database $\mathcal{D}=\{(I_d,\mathbf c_d)\}$ of images with known coordinates, and the coordinates of the retrieved image are returned as the query's. Every image is a grid of $N$ patches, $I=[\,p_1,\dots,p_N\,]$, and passes once through a frozen DINOv2/DINOv3 backbone, from which we keep the value facet of one block, the output of its value projection \citep{vitfacets,effovpr}. A PCA is fitted across patch tokens collected from a few hundred unlabelled database images and then applied to every token, reducing it to $C{=}512$ channels; tokens are $\ell_2$-normalized. An image is therefore a matrix of $N$ unit vectors, $F=[\,\mathbf f_1,\dots,\mathbf f_N\,]^{\top}\in\mathbb R^{N\times C}$, and two tables of similarities follow from it: $G=FF^{\top}$ inside one image, with $G_{ij}=\mathbf f_i^{\top}\mathbf f_j$ the similarity between two of its patches, and $S=QD^{\top}$ between a query and a candidate, with $S_{ij}=\mathbf q_i^{\top}\mathbf d_j$. Both stages read nothing but these two tables. Appendix~\ref{app:hyper} sweeps the block, the facet and the shortlist depth.

\subsection{Self-similarity weight}
\label{sec:feat}
Sky, pavement and a facade of identical windows fill an image with near-copies of the same content. We want ten nearly identical sky patches to contribute about as much as one unique patch, rather than ten times as much, so each patch is weighted before either stage uses it.

For token $i$, we want the total weight of the tokens similar to it to be about constant:
\begin{equation}\label{eq:demo}
  \sum_j G_{ij}\,w_j = 1,
  \qquad\text{in matrix form}\qquad
  G\mathbf w=\mathbf 1,
\end{equation}
the democratic-weighting condition of \citet{democratic} and \citet{gmp}. We impose it on the thresholded table $\hat G_{ij}=\mathbb 1[\,G_{ij}>\tau\,]$, which counts near-copies rather than grading them. The condition then admits a closed-form solution,
\begin{equation}\label{eq:weight}
  w_i=\frac{1}{n_i},
  \qquad
  n_i=\sum_j \hat G_{ij}.
\end{equation}
A patch recurring twenty times in its image therefore receives one twentieth of the weight of a patch that occurs once. Appendix~\ref{app:ridge} gives the derivation.

\subsection{First stage}
\label{sec:global}
Stage 1 needs a fixed-size descriptor for each image so that all database images can be searched efficiently. We obtain it as the weighted second moment of the patch features.

Take a patch $\mathbf q$ from the query and a patch $\mathbf d$ from a candidate. Squaring their similarity gives $(\mathbf q^{\top}\mathbf d)^2=\langle\,\mathbf q\mathbf q^{\top},\ \mathbf d\mathbf d^{\top}\,\rangle$: a comparison of two matrices, each built from one image alone. Summing over all patch pairs therefore collapses into a single comparison between two per-image matrices,
\begin{equation}\label{eq:so-deriv}
  \sum_{i,j} w_{Q,i}\,w_{D,j}\,\big(\mathbf q_i^{\top}\mathbf d_j\big)^{2}
  =\big\langle\, G_C(Q),\ G_C(D)\,\big\rangle,
  \qquad
  G_C(F)=\frac{1}{\sum_i w_i}\sum_i w_i\,\mathbf f_i\mathbf f_i^{\top}.
\end{equation}
$G_C$ records how an image's features co-occur across channels, ignoring where in the frame they appeared, and it keeps much more of the image than an average of the same tokens would (Appendix~\ref{app:coarsegrid}). Appendix~\ref{app:factorize} treats other powers.

We store $G_C$ flattened, take the square root of each entry, and $\ell_2$-normalize:
\begin{equation}\label{eq:stage1}
  \psi(F)\;=\;\frac{\rho\big(\operatorname{vec}(G_C(F))\big)}{\lVert\rho\big(\operatorname{vec}(G_C(F))\big)\rVert_2},
  \qquad
  \rho(u)=\operatorname{sign}(u)\sqrt{|u|}.
\end{equation}
The square root is the power normalization of \citet{improvedfisher}, standard for Fisher vectors and VLAD. It serves the same end as the weight, acting after aggregation rather than on the patches before it: a repeated element makes a few entries of the descriptor very large, and those entries would otherwise dominate the comparison between two images. A whitened PCA then reduces the descriptor to $2048$ dimensions and the scan returns $P{=}\min(1000,|\mathcal{D}|)$ candidates. The same weight decides what to store, each image keeping its $1024$ highest-weight patches (\S\ref{sec:stage1abl}). Both PCAs are fitted on the deployment database and nothing else is fitted at all.

\subsection{Second stage}
\label{sec:core}
For each query patch we find its most similar patch in the candidate image and add up those similarities:
\begin{equation}\label{eq:stage2}
  s(Q,D)=\sum_{i=1}^{N_Q} w_{Q,i}\;\mathbb 1[\,m_i>\theta\,]\;m_i,
  \qquad
  m_i=\max_{j} S_{ij},
\end{equation}
the \textsc{MaxSim} rule of \citet{colbert}, weighted as in \S\ref{sec:feat}. Sky, pedestrians and occluders have no counterpart in the other image, so a patch counts only if its best match clears a confidence threshold $\theta$, fixed at $0.65$ everywhere (Appendix~\ref{app:calib}).

\textsc{MaxSim} cannot be represented by a single fixed-size descriptor per image, so we apply it only to the shortlisted candidates (Appendix~\ref{app:nofactor}). A method that stores a single vector per image is thereby denied this stage, and must train its pooling until that vector separates places on its own \citep{netvlad}. This rule is denoted \textsc{selfw\_conf} in the tables, and Figure~\ref{fig:vis-m1} shows the matches that survive the threshold. Appendix~\ref{app:effo-matched} compares it against a mutual-match variant and against \textsc{EffoVPR}'s attention-selected rule on an identical shortlist.
